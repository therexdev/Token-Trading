# Trade Koinos — landing page

Self-contained marketing homepage for **tradekoinos.com** (the app itself
lives at https://app.tradekoinos.com/).

`index.html` is fully standalone — fonts, the app screenshot, all CSS and
JS are inlined, so there are no external requests. Upload it to the web
root of tradekoinos.com and you are done.

To update the screenshot or copy, edit `index.html` directly, or regenerate
from the app.
